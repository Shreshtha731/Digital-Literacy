## 📖 Project Overview
This repository contains my submissions for the Digital Literacy project. The goal of this project is to build a strong foundation in digital citizenship, professional online presence, and cybersecurity awareness. As an engineering student, these tasks helped me transition from a casual technology user to a responsible digital professional by utilizing various platforms, practicing safe communication, and understanding modern cyber threats.
